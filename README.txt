=======================================================================
 ПОИСК ЦЕН НА ЛЕКАРСТВА В БЛИЖАЙШИХ АПТЕКАХ КРАСНОЯРСКА (через 24lek.ru)
=======================================================================

ЧТО ЭТО
-------
Программа:
 1. Спрашивает у вас адрес.
 2. Определяет его координаты через Dadata.
 3. Находит аптеки в радиусе 300 м из файла apteki.json.
 4. Берёт список лекарств из products.xlsx.
 5. Для каждого лекарства ищет цены на сайте 24lek.ru.
 6. Сопоставляет цены с найденными ближайшими аптеками.
 7. Сохраняет итог в report.xlsx.


-----------------------------------------------------------------
ШАГ 1. Установка Python (если ещё не установлен)
-----------------------------------------------------------------
Скачайте Python 3.10+ с https://www.python.org/downloads/windows/
При установке ОБЯЗАТЕЛЬНО поставьте галочку "Add python.exe to PATH".


-----------------------------------------------------------------
ШАГ 2. Распаковка проекта
-----------------------------------------------------------------
Распакуйте архив в любую папку, например:
    C:\24lek_project\

В папке должны лежать:
    main.py
    config.py
    geocoder.py
    normalizer.py
    pharmacies.py
    lek24_parser.py
    requirements.txt
    apteki.json        <- ваш файл со списком аптек
    products.xlsx       <- ваш файл со списком препаратов
    README.txt


-----------------------------------------------------------------
ШАГ 3. Установка зависимостей
-----------------------------------------------------------------
Откройте командную строку (cmd) в папке проекта:
  - зайдите в папку в Проводнике,
  - в адресной строке Проводника введите cmd и нажмите Enter.

Выполните:
    pip install -r requirements.txt


-----------------------------------------------------------------
ШАГ 4. Получение бесплатного ключа Dadata
-----------------------------------------------------------------
1. Зайдите на https://dadata.ru/api/suggest/address/
2. Зарегистрируйтесь (бесплатно).
3. Скопируйте "API-ключ" (Suggestions API token) из личного кабинета.
4. Откройте файл config.py любым текстовым редактором (Блокнот подойдёт).
5. Замените строку:
       DADATA_TOKEN = "ВАШ_API_KEY_DADATA"
   на:
       DADATA_TOKEN = "ваш_реальный_токен"
6. Сохраните файл.


-----------------------------------------------------------------
ШАГ 5. Подготовка своих данных
-----------------------------------------------------------------
apteki.json — список реальных аптек Красноярска с их ID на сайте 24lek.ru.

ВАЖНО: поле "id" в apteki.json — это числовой идентификатор аптеки
на самом сайте 24lek.ru (тот же ID, что используется в ссылке вида
24lek.ru/karta.php?apteka=ID). Сопоставление цены с конкретной
аптекой происходит СТРОГО по этому ID, без сравнения названий/адресов.
Если у вас этого списка нет — его нужно собрать заранее (например,
обходом страницы apteki.php на сайте), либо обратиться за готовым
файлом с полным перечнем аптек города.

products.xlsx — один столбец с полными названиями препаратов
(как в вашем примере). Программа сама всё нормализует.

Оба файла должны лежать рядом с main.py.


-----------------------------------------------------------------
ШАГ 6. Запуск
-----------------------------------------------------------------
В командной строке (в папке проекта) выполните:

    python main.py

Программа спросит:

    Введите адрес (например: Свободный 60):

Введите нужный адрес и нажмите Enter. Дальше программа всё сделает сама
и покажет прогресс по каждому препарату. По завершении рядом появится
файл report.xlsx — откройте его в Excel.


-----------------------------------------------------------------
СТРУКТУРА ОТЧЁТА (report.xlsx)
-----------------------------------------------------------------
Столбец A       — нормализованное название препарата (то самое,
                  которое реально отправлялось в поиск на 24lek.ru),
                  например: "пенталгин 12 таб"

Столбцы B, C... — по одному на каждую найденную рядом аптеку,
                  заголовок вида:
                  "Аптека Эконом — Свободный 50 (98 м)"

Ячейки          — минимальная найденная цена препарата в этой аптеке.
                  Пустая ячейка = в этой аптеке данный препарат
                  на 24lek.ru не найден.


-----------------------------------------------------------------
НАСТРОЙКИ (config.py)
-----------------------------------------------------------------
RADIUS_METERS     — радиус поиска аптек в метрах (по умолчанию 300).
REQUEST_DELAY     — пауза между запросами к 24lek.ru, секунды
                    (не уменьшайте сильно — сайт может заблокировать).
MAX_PAGES_PER_QUERY — защитный лимит "страниц" выдачи на один препарат.


-----------------------------------------------------------------
КАК УСТРОЕН ПАРСЕР (коротко, для разработчика)
-----------------------------------------------------------------
Сайт 24lek.ru не отдаёт цены через JSON/AJAX и не хранит их в
window.goods — это было явно проверено и опровергнуто. Цены лежат
прямо в HTML-ответе по адресу:

    GET https://24lek.ru/action.php?kray=0&city=0&raon=0&query=<запрос>

Внутри <div id='maintable'> идут блоки:

    <div id='article1'>
      <span>Название товара у аптеки</span>
      <span>Кол-во на складе</span>
      <span>ЦЕНА</span>
      <span><a href="javascript:open_in_map(ID)">Название аптеки Адрес</a></span>
      <span><a href="tel:...">телефон</a></span>
      <span>дата обновления</span>
    </div>

Если найденных товаров больше 50 — остальные "страницы" подгружаются
через:
    POST https://24lek.ru/action2.php
    data: a=<запрос>, city=0, raon=0, num=50/100/150..., code=<токен со страницы>

Число внутри open_in_map(ID) — это тот же числовой ID аптеки, что
хранится в поле "id" вашего apteki.json (проверено: ID=521 на сайте
соответствует странице 24lek.ru/karta.php?apteka=521 с полным
совпадением названия и адреса аптеки). Поэтому сопоставление цены
с конкретной аптекой идёт напрямую по числовому ID, без нечёткого
сравнения названий или адресов.

Старая ошибка парсера (цена бралась как spans[1], что в части
карточек было количеством товара, а не ценой) исправлена: теперь
цена определяется по регулярному выражению вида "ЧИСЛО.ЧИСЛО" среди
всех span внутри карточки, а не по фиксированному индексу.


-----------------------------------------------------------------
ВОЗМОЖНЫЕ ПРОБЛЕМЫ
-----------------------------------------------------------------
"ОШИБКА геокодирования: Не задан DADATA_TOKEN"
    -> впишите свой токен в config.py (см. ШАГ 4).

"В указанном радиусе аптек не найдено"
    -> либо увеличьте RADIUS_METERS в config.py, либо проверьте,
       что apteki.json реально содержит аптеки рядом с этим адресом.

Цены не находятся ни для одного препарата
    -> проверьте, что apteki.json содержит РЕАЛЬНЫЕ числовые ID аптек
       с сайта 24lek.ru (не выдуманные), иначе сопоставление по ID
       не найдёт совпадений.

Сайт слишком долго отвечает / блокирует
    -> увеличьте REQUEST_DELAY в config.py.
